# DAY11 阅读立场检测综述

阅读立场检测综述，了解任务定义与数据集 → [Stance Detection: A Survey](https://dl.acm.org/doi/epdf/10.1145/3369026)

## 一、论文核心主题

这篇综述主要介绍立场检测如何判断一段文本对某个目标是支持、反对还是没有明确态度，并梳理了相关任务、系统流程、主要方法和应用方向。

## 二、立场检测的几种定义

### 1. 通用立场检测

例子：

目标是“是否支持死刑”，文本是“死刑能震慑严重犯罪，我支持保留”。

系统要判断这段话对“死刑”的立场是：支持。

### 2. 多目标立场检测

例子：

文本是“我支持加强环保政策，但反对提高燃油税”。

这里同时涉及“环保政策”和“燃油税”两个目标。

系统需要分别判断：

- 对“环保政策”：支持
- 对“燃油税”：反对

### 3. 跨目标立场检测

例子：

模型训练时看过很多关于“乔丹”的支持或反对文本，但测试时要判断用户对“科比”的立场。

也就是说，系统要把学到的立场判断能力迁移到新目标上。

### 4. 谣言立场分类

例子：

谣言是“某地发生严重疫情”。

不同帖子可能是：

- “是真的，我朋友就在现场”：支持谣言
- “官方已经辟谣了”：否认谣言
- “有可靠来源吗？”：质疑谣言
- “大家都在讨论这个”：评论谣言

系统要判断帖子对谣言的态度。

### 5. 假新闻立场检测

例子：

标题是“某疫苗会导致严重副作用”，正文是“多项研究没有发现该疫苗与严重副作用有关”。

系统要判断正文和标题的关系：反驳。

## 三、与其他 NLP 任务的关系

### 1. 与情感分析

例子：

文本：“太好了，这项愚蠢的政策终于被取消了。”

情感上是正面，因为作者觉得“太好了”；但如果目标是“这项政策”，立场是反对。

所以情感分析看情绪好坏，立场检测看对目标站哪边。

### 2. 与情绪识别

例子：

文本：“我对这项判决非常愤怒。”

情绪识别会判断出“愤怒”；立场检测还要进一步判断作者是支持还是反对“这项判决”。

情绪可以帮助判断立场，但不能直接等同于立场。

### 3. 与观点识别

例子：

一段政治评论中没有明确说支持哪项政策，但语言风格和关注点明显偏向某个政治阵营。

观点识别可能判断作者属于“保守派”或“自由派”；立场检测则更关注作者是否支持某个具体目标，比如“移民政策”。

### 4. 与讽刺/反讽检测

例子：

文本：“这政策真是太聪明了，成功让所有人都更麻烦。”

表面看像夸奖，实际是在讽刺。

如果系统识别不出讽刺，就可能把反对误判成支持。

### 5. 与争议检测

例子：

系统先发现“是否取消考试”是一个争议话题，很多人意见对立；然后再判断每条评论是支持取消考试，还是反对取消考试。

争议检测可以帮助找到适合做立场检测的话题。

### 6. 与论证挖掘

例子：

文本：“我反对提高学费，因为这会增加低收入家庭负担。”

论证挖掘关注“因为这会增加低收入家庭负担”这个理由；立场检测关注作者对“提高学费”的态度是反对。

理由结构能帮助判断立场。

### 7. 与偏见语言检测

例子：

文本：“这些所谓专家又在为错误政策找借口。”

“所谓专家”“找借口”带有明显倾向。

偏见语言检测会识别这种倾向性表达；立场检测会进一步判断作者对“该政策”是反对。

## 四、通用立场检测系统架构

简洁流程：

```text
输入：文本 + 目标
        ↓
文本预处理
去除 URL、用户名、标点、停用词
分词、规范化、大小写处理
        ↓
特征或表示构建
n-gram、词向量、情感信息、上下文信息等
        ↓
立场分类模型
传统分类器 / 深度学习模型 / 集成模型
        ↓
输出立场
支持 / 反对 / 中立或无明确立场
```

常见两阶段结构：

```text
第一步：判断文本是否对目标表达了明确立场
        ↓
如果有立场，再判断是支持还是反对
        ↓
如果没有立场，输出 Neither
```

## 五、主要方法分类

### 深度学习方法

深度学习方法主要用神经网络自动学习文本表示，减少对人工设计特征的依赖。

常见模型包括 RNN、LSTM、BiLSTM、GRU、CNN、Attention 模型、Memory Network，以及 BERT 等预训练语言模型。

简单理解：

- LSTM / GRU：适合处理一句话中前后词语的关系。
- CNN：适合抓局部词组特征，比如某些固定表达。
- Attention：让模型重点看和目标最相关的词。
- BERT：利用大规模预训练语言知识，更好理解上下文。

例子：

目标是“气候变化”，文本是“那些否认全球变暖的人根本无视科学证据”。

Attention 模型可能会重点关注“否认”“无视科学证据”等词，从而判断作者支持“气候变化是真实问题”。

论文观点：

- LSTM 是立场检测中常用的深度学习模型。
- CNN 也经常用于短文本立场检测。
- 加入 Attention 往往能提升效果。
- 深度模型不一定总是超过传统方法，尤其在数据较少时表现可能不稳定。
- BERT 这类预训练模型是后续重要方向。

### 集成学习方法

集成学习方法不是只用一个模型，而是把多个模型的判断结果组合起来。

常见方式包括多数投票、Random Forest、Bagging、Boosting、Stacking，也包括 CNN + LSTM、BiGRU + CNN + Attention，以及多个传统模型和神经模型的组合。

简单理解：

```text
模型 A 判断：支持
模型 B 判断：支持
模型 C 判断：反对
最终结果：支持
```

例子：

判断一条关于“疫苗”的评论时，SVM 根据关键词判断为反对，LSTM 根据上下文判断为反对，CNN 根据局部表达判断为支持。集成模型会综合这些结果，再给出最终立场。

论文观点：

- Random Forest 是常见的集成方法。
- 一些研究会组合 CNN、LSTM、GRU 和 Attention。
- 集成学习有潜力提升效果。
- 但相关研究数量少于深度学习和传统机器学习，还需要更多比较实验。
